# Mobile-Sales-Dashboard
A Power BI dashboard that analyzes mobile phone sales across major cities, showing total sales, monthly trends, top-selling models, payment methods, and customer ratings. This project highlights key business insights using interactive visuals, DAX measures, and data modeling.

# 📱 Mobile Sales Dashboard — Power BI Project

This Power BI dashboard provides a detailed analysis of mobile phone sales, covering sales trends, quantity sold, payment behavior, top-performing models, customer ratings, and city-level insights.

## 📊 Project Overview

The goal of this dashboard is to help businesses understand:

Total sales performance

Monthly quantity trends

Top-selling mobile models

City-wise distribution

Customer ratings

Payment methods used

Day-wise sales patterns

This dashboard gives a complete picture of customer buying behavior and product performance.
